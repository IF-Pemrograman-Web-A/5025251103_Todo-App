## Description
Pengembangan Todo App dari versi HTML/JavaScript menjadi aplikasi berbasis PHP dengan database MySQL.

- Menambahkan menu bar dengan dua menu: **Personal** dan **Shared**
- Memigrasikan HTML ke PHP dan memecahnya menjadi modul:
  - `config.php` : koneksi database
  - `menu-bar.php` : menu navigasi Personal / Shared
  - `content.php` : daftar todo dan form
  - `index.php` : halaman utama yang menggabungkan semua modul
- Membuat struktur database beserta dummy data (`data.sql`)
- Mengimplementasikan CRUD dengan PHP:
  - Create : `create.php`
  - Read : `content.php`
  - Update : `update.php`
  - Delete : `delete.php`
- Menyesuaikan `script.js` (fitur edit dan dark mode) dan `style.css` (tampilan menu bar)
